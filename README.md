# Esencia — Restaurant Website

**Live Website:** [https://dineesencia.com](https://dineesencia.com)

## Overview

Esencia is a restaurant website developed for Esencia at the St. Anthony Hotel in San Antonio, Texas.

The website presents the restaurant's identity, culinary influences, menu, and private dining experience through an elegant digital experience inspired by its heritage and contemporary atmosphere.

The design combines refined typography, rich dark tones, warm gold accents, and editorial photography to create a sophisticated online presence.

## Design Direction

The visual identity balances sophistication, warmth, and modern elegance.

- **Color palette:** Deep charcoal, muted olive, warm neutrals, and gold accents.
- **Typography:** Editorial serif typography paired with clean sans-serif lettering.
- **Visual approach:** Large-format photography, spacious layouts, and understated design details.
- **User experience:** Responsive layouts designed for desktop, tablet, and mobile devices.

## Website Structure

The website is organized around six primary sections:

| Page | Description |
|---|---|
| Home | Introduces Esencia and establishes the restaurant's visual identity. |
| About | Shares the restaurant's story, culinary influences, and identity. |
| Menu | Showcases the restaurant's food and beverage offerings. |
| Private Dining | Presents private dining experiences and event opportunities. |
| Gallery | Highlights the restaurant, atmosphere, and dining experience through photography. |
| Contact | Provides essential restaurant information and contact details. |

## Features

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project directory:

```bash
cd esencia-rest
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The local development server will be available at the URL provided by Vite, typically:

```text
http://localhost:5173
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the Vite development server. |
| `npm run build` | Builds the production-ready application. |
| `npm run preview` | Previews the production build locally. |
| `npm run lint` | Runs ESLint to check code quality. |

## Production Build

To generate a production build:

```bash
npm run build
```

Vite generates the optimized production files in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```

## Project Goals

The goal was to create a digital presence that reflects Esencia's identity while making essential restaurant information accessible and easy to navigate.

The website was designed to:

- Establish a cohesive online brand experience.
- Present the restaurant's culinary identity.
- Make menu and dining information easy to access.
- Showcase the atmosphere through photography.
- Provide a polished experience across devices.
